# underdog-web-challenge
이동주
지원동기: 머릿속의 아이디어를 구상에만 머물게 하지 않고, 직접 코딩하며 실제 동작하는 웹 서비스로 구현하는
역량을 키우고 싶습니다. 기획부터 개발, 그리고 창업으로 이어지는 전체 사이클을 직접 경험하며 
실전 감각을 탄탄하게 다지는 것이 목표입니다.
그렇기에 동아리 활동에서 사이트나 웹을 만드는 방법과 여러 사이트의 활용도를 더 깊이 있게 배우고싶습니다.




웹 개발의 기초인 HTML과 CSS를 학습하고, 기획해 둔 아이디어를 실제 동작하는 웹 서비스로 구현하기 위한 첫걸음으로 제작한 자기소개 페이지입니다. 

사용한 기술
- **HTML5**: 웹페이지의 구조와 뼈대 설계
- **CSS3**: Flexbox를 활용한 반응형 레이아웃 및 디자인


주요 기능
- **반응형 웹**: PC와 모바일 화면 크기에 맞춰 레이아웃이 자동 변환됩니다.
- **다크 모드**: 우측 상단 버튼을 통해 라이트/다크 테마를 전환할 수 있습니다.

  실행 방법 및 배포 링크
- **배포 주소**: https://dongjulee54.github.io/underdog-web-challenge/

  작업하며 배운 점
그동안 Java나 Linux, 알고리즘 같은 백엔드와 시스템적인 로직에 집중해왔다면, 이번 챌린지를 통해 사용자 눈에 직접 보이는 웹 프론트엔드의 뼈대(HTML/CSS)를 확실하게 다질 수 있었습니다. 앞으로 제가 짜는 서버나 기능들을 이렇게 직접 만든 깔끔한 웹 화면 위에 올려, 기획부터 개발, 런칭까지 혼자서 완벽하게 사이클을 돌릴 수 있는 개발자로 성장하고 싶습니다.
